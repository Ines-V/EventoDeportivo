GESTION DE EVENTOS DEPORTIVOS DE UN POLIDEPORTIVO.

Desarrolla un programa en Java que permita gestionar los eventos deportivos que se celebran en un polideportivo durante un fin de semana. 

El programa debe permitir registrar, consultar y gestionar los eventos deportivos, almacenando información básica como el nombre del evento, el deporte, el día, el horario y el número de participantes. El usuario podrá realizar distintas operaciones desde un menú de consola. 

El programa deberá permitir: 

• Registrar nuevos eventos deportivos. 

• Mostrar todos los eventos registrados. 

• Buscar eventos por deporte o por día. 

• Consultar el número total de eventos y participantes. 

• Eliminar un evento registrado. 

Condiciones: 

• El programa debe desarrollarse en Java. 

• Se utilizarán variables, estructuras de control, métodos y estructuras de almacenamiento adecuadas.

• La interacción con el usuario se realizará mediante consola. 

• El diseño de las variables, los métodos y la organización del código queda a criterio del alumno. 

Objetivo: Resolver el problema aplicando los conocimientos de programación adquiridos, buscando una solución funcional, clara y bien organizada.
